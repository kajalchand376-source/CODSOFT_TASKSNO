# 📌 Tasks Completed

## 🔹 Task 1 — Network Packet Analyzer

A Python-based network packet analyzer was developed to capture and analyze network packets.

### Features

- Captures network packets using Python and Scapy
- Displays Source IP address
- Displays Destination IP address
- Identifies the protocol
- Displays packet information/data
- Provides a simple command-line interface for packet analysis

### Technology Used

- Python
- Scapy

### Main File

`packet_analyzer.py`

## 🔹 Task 3 — Secure Code Assessment

A Python user registration and login application using SQLite was examined for common security weaknesses.

Two versions were prepared:

- Vulnerable version
- Secure version

### Security Assessment

The vulnerable application was reviewed to identify security weaknesses. The identified password-storage weakness was addressed in the secure implementation using a secure password-hashing approach.

### Project Files

- `vulnerable_app.py`
- `secure_app.py`
- `users.db`
- `secure_users.db`
- `requirements.txt`
- `Task_3_Secure_Code_Assessment_Report.pdf`

### Technology Used

- Python
- SQLite
- Python Standard Library
