# CODSOFT Cyber Security Internship - Task 1

## Network Packet Analyzer

This project was completed as part of the CodSoft Cyber Security Internship.

### Task Objective

The objective of this task is to create a simple network packet analyzer using Python. The analyzer captures and examines network packets and displays useful information such as source IP address, destination IP address, protocol, and packet details.

### Technologies Used

- Python
- Scapy

### Project File

- `packet_analyzer.py` - Python program for capturing and analyzing network packets.

### Features

- Captures network packets
- Displays source and destination IP addresses
- Identifies network protocols
- Displays packet information
- Helps understand basic network traffic analysis

### Conclusion

This task provided practical experience with network packet analysis and helped in understanding how network traffic can be captured and examined for cybersecurity purposes.
